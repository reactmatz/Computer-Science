# Computer Science

Computer science course plan, following the [OSSU Computer Science curriculum](https://github.com/ossu/computer-science).

Every day has its own file with the topic, a short task list, a place for notes and, on coding days, a starter file in the week's `code/` folder.

## How it works

- **Pace:** about 60–90 minutes a day.
- **Monday–Friday:** learn, practice, apply — three sessions per topic, plus project days.
- **Saturday:** weekly review and flashcards or day off.
- **Sunday:** light day, ~20 minutes of review or dar off.
- **Layout:** `year/month/week-NN/YYYY-MM-DD-Day.md`
- **Plan:** not get crazy.

Start with [the first day](2022/02-February/week-06/2022-02-07-Monday.md) and track progress in [PROGRESS.md](PROGRESS.md).
